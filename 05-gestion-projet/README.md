# Gestion de projet

Ce dossier documente le pilotage du projet JobTracker.

## Fichiers

- `synthese_jira.md` : role du board Jira, volumes d'export, jalons et decisions de presentation GitHub.
- `registre_risques_decisions.md` : risques, impacts et mitigations retenues pour la V1 publique.

## Positionnement

Jira reste l'outil operationnel de suivi. GitHub presente uniquement une version portfolio anonymisee : dataset public, documentation, requetes SQL et roadmap.

## Decision cle V1

Le projet est presente comme une V1 livree mais vivante. La partie Power BI continue d'evoluer, et la connexion directe Jira -> Power BI reste une amelioration V2.
