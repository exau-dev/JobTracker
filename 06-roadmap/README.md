## Definition of Done publique

Une version publique est consideree prete quand elle contient :

- aucune donnee personnelle ou nom d'entreprise ;
- un README coherent avec l'etat reel du projet ;
- un dataset exploitable ;
- des requetes qui fonctionnent sur le schema documente ;
- des captures uniquement lorsqu'elles representent un dashboard stable.
